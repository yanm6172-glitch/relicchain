# 09 建为历保联系话术与谈判指南

> 一次沟通只追求一个目标：书面授权 / 客户转介 / 合作备忘（三选一）。

## 0. 姿态总纲

**平等合作，不是求职。** 它冲刺"文化遗产保护第一股"需要"数字化 + 区块链"的资本故事与校企合作素材，你们要渠道与背书——互相需要。永远用"联合试点"开口，不用"求帮忙"开口。

## 1. 微信开场（首选渠道）

### 版本 A · 和对接人还算熟

【称呼】您好，好久不见！我们几个之前参与过绵阳碧水寺摩崖造像扫描项目的同学，现在在上海做文物数字化创业，方向是"文物数字资产存证 + 授权"。

想约您 15 分钟，汇报一个我们想和建为一起做的联合小试点：用当时扫描的文物做 10 件存证演示（免费、双品牌、不商用），顺带请教两个问题。您这周哪天方便？

### 版本 B · 不太熟

【称呼】您好，冒昧打扰。我们是【学校】学生创业团队，曾参与建为的碧水寺摩崖造像扫描工作，对建为在文保科技上的积累非常敬佩。

我们在做文物数字资产存证与授权的小产品，想请教：是否有可能和建为做一个联合小试点——用我们当时扫描的文物数据做 10 件存证演示（免费、双品牌、不商用）？方便的话我把一页纸说明发给您。

## 2. 邮件版（正式）

**主题**：关于与建为历保联合开展"文物数字资产存证"小试点的提议

**正文骨架**：
1. 自我介绍：学校 + 创业项目 + 与建为的渊源（参与过扫描项目）；
2. 提议：联合试点内容（10 件文物、存证 + 验证页、双品牌、免费、不商用）；
3. 需要的支持（三选一）：书面演示授权 / 引荐馆方 / 合作备忘录；
4. 附件：一页纸 BP（BP-一页纸商业计划书.md）；
5. 结尾：想约 15 分钟电话，本周何时方便。

## 3. 见面 / 电话要点（10 分钟结构）

| 时间 | 内容 |
| --- | --- |
| 1 分钟 | 我们是谁 + 与建为的渊源 |
| 2 分钟 | 现场演示：存证演示 demo + 可视化总览 |
| 3 分钟 | 说清"我们不要钱，要什么"（三选一） |
| 2 分钟 | 给对方理由：建为冲"第一股"需要数字化故事，学生团队案例是好素材 |
| 2 分钟 | 确认下一步动作与时间点 |

## 4. 常见回应与应对

| 对方说 | 应对 |
| --- | --- |
| "照片版权在博物馆" | 那更好——请帮我们引荐馆方，三方签协议，馆方同样受益 |
| "你们想拿照片干嘛" | 只做联合演示，所有展示标注来源，不对外商用 |
| "没预算" | 我们免费做试点，要的是授权和转介，不是钱 |
| "考虑考虑" | 理解。那我【周X】再跟进一次，可以先把一页纸转给相关同事吗 |
| 直接拒绝 | 退而求其次：一句推荐 / 一个馆方联系人 / 允许在 BP 里写"参与过建为项目" |

## 5. 红线（绝不做）

- 授权前拿照片做任何对外商用或演示；
- 自称"已与建为合作"——只可说"参与过建为的碧水寺摩崖造像扫描项目"；
- 贬低馆方或同行；
- 在公开材料透露分账比例等商业条款。

## 6. 跟进节奏

- 沟通当天：发感谢消息 + 15 分钟内补发要点纪要；
- 3 天未回：追一次；
- 每周：推进一个明确动作（见面 / 引荐 / 签字），绝不让对话"挂起"。

## 7. 拿到授权后的 30 天（衔接 08 文档的 60 天计划）

| 周 | 动作 |
| --- | --- |
| 第 1 周 | 把 10 件真实照片/元数据替换进 存证演示demo.html 的示例数据 |
| 第 2 周 | 开放联盟链真实存证（蚂蚁链 / 至信链） |
| 第 3 周 | 与建为/馆方做一次联合演示，拍现场照片当路演素材 |
| 第 4 周 | 把"建为联合试点"写进 BP 与大赛申报材料 |
