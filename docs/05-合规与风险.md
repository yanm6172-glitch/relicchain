# 05 合规与风险

> 文档定位：回答"红线在哪、风险有哪些、怎么防"。本节需法务复核后定稿。

## 1. 适用法规清单

| 法规/规范 | 与项目相关的要点 |
| --- | --- |
| 《中华人民共和国文物保护法》（2023 修订） | 馆藏文物数字化成果管理、文物数据安全、禁止违规买卖文物 |
| 《中华人民共和国数据安全法》 | 数据分类分级、重要数据保护 |
| 《中华人民共和国网络安全法》 | 等级保护、安全义务 |
| 《中华人民共和国密码法》 | 商用密码使用（SM 系列） |
| 《中华人民共和国个人信息保护法》 | 公众端个人信息处理 |
| 《数据出境安全评估办法》 | 涉外展览/合作涉及数据出境需评估 |
| 《区块链信息服务管理规定》 | 区块链信息服务提供者需备案 |
| 三协会《关于防范 NFT 相关金融风险的倡议》等 | 数字藏品不得金融化、证券化、炒作 |

## 2. 文物数据分级策略

| 级别 | 数据示例 | 处理策略 |
| --- | --- | --- |
| 核心数据 | 涉密文物、未公开的馆藏信息 | 不数字化上链，物理隔离 |
| 重要数据 | 高等级文物完整模型（L0/L1） | 加密存储、授权访问、禁止出境 |
| 一般数据 | 已公开的元数据、展示级模型（L2/L3） | 分级开放、留痕审计 |

## 3. 数字藏品边界（重要）

- 文物**本体**不得以任何形式进行所有权分割与交易；
- 可探索的是**衍生数字版权**（官方数字影像、三维模型的限量授权使用），且：
  - 限量发行、实名购买；
  - 不支持二级市场炒作（或仅支持合规流转机制）；
  - 明确声明不构成金融产品；
- 是否做数字藏品、何时做，须在 M4 阶段单独合规论证（见 06 文档）。

## 4. 风险登记表

| # | 风险 | 概率 | 影响 | 对策 |
| --- | --- | --- | --- | --- |
| R1 | 源头数据造假（上链了假数据） | 中 | 高 | 权威机构签名背书、抽检复核、造假追责机制 |
| R2 | 机构私钥丢失/泄露 | 低 | 极高 | KMS/HSM 托管、多签、密钥轮换与恢复预案 |
| R3 | 智能合约漏洞 | 低 | 高 | 第三方审计、最小权限、治理升级机制 |
| R4 | 政策变化（如数字藏品收紧） | 中 | 中 | 可治理架构、合规顾问、功能模块化可下线 |
| R5 | 技术过时/格式废弃 | 中 | 中 | 开放标准、格式迁移计划、链适配层 |
| R6 | 隐私与数据泄露 | 低 | 高 | 最小化采集、分级访问、全链路加密与审计 |
| R7 | 节点机构退出/不活跃 | 中 | 中 | 治理合约准入退出规则、共识参数可调 |

## 5. 备案与资质路径

1. 区块链信息服务备案（网信办）；
2. 商用密码产品/服务合规选用；
3. 涉及面向公众服务时完成等级保护测评；
4. 与试点馆签署数据安全与授权协议。
