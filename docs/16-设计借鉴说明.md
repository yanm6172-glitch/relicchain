## 3. 借鉴原则

1. **借结构与版块划分，不借内容**：参考的是历史文化街区，我们的是文物区块链平台，业务内容全部原创；
2. **借配色与视觉语言，不抄图**：大屏深青蓝+金的"文化科技"色感、官网浅色+蓝点缀的清爽感；
3. **借"三件套"思路**：官网（对外形象）+ 小程序（移动端操作）+ 大屏（数据展示）——文博链已补齐：平台（小程序形态）+ 官网 + 大屏；
4. 参考项目的设计稿为版权作品，本项目仅做风格与结构参考，无任何素材挪用。
