| --- | --- | --- |

## 3. 技术参数

| 参数 | 值 |
| --- | --- |
| 哈希算法 | SHA-256（真实本地计算） |
| 共识演示 | 工作量证明（难度 1–3 可调）+ 4 节点多数共识展示 |
| 数据存储 | 本机浏览器 localStorage（离线可用，不上传服务器） |
| 运行环境 | Chrome / Edge 桌面与安卓（建议最新版）；iOS Safari 基本可用 |
| 体积 | 全套 < 1MB，单文件平台 ~73KB |

## 4. 系统要求

- 电脑：任意 Windows/macOS + Chrome/Edge；
- 手机：安卓 + Chrome，或 iOS + Safari；
- 扫码功能：支持 BarcodeDetector 的浏览器（Chrome 安卓/桌面）；不支持时手动输入兜底；
- 拍照取证：带摄像头的设备（桌面可上传照片）。
