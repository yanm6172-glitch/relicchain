# 21 用户协议与免责声明

> 商品化必备。正式商用前请法务复核。

## 1. 协议要点（平台内已内置提示）

1. 本产品为演示/试点版本，数据存储于使用者的本机浏览器，不上传任何服务器；
2. 内置文物数据均为**示例数据**（碧水寺项目为背景的占位内容）；
3. 使用真实文物数据前，必须取得馆方/权利方**书面授权**；
4. 平台不涉及文物实物交易、不涉及数字藏品发行；
5. 区块链部分为**演示级实现**（真实哈希与工作量证明，联盟共识为模拟展示），生产环境对接真联盟链方案见 docs/02、docs/04。

## 2. 隐私与数据声明

- 账号密码仅存本机（明文，演示环境），正式版应改为哈希存储 + 服务端鉴权；
- 照片取证仅计算 SHA-256 指纹存证，原始照片留在本机/由馆方管理；
- 清除浏览器数据或点击"重置全部数据"即删除全部数据。

## 3. 免责声明

- 演示版不保证数据的跨设备同步与灾备（正式版对接链后解决）；
- 因使用者未取得授权而使用真实文物数据引发的纠纷，由使用者承担；
- 产品持续迭代，功能与参数以最新版《产品规格书》为准。

## 4. 对外承诺口径（销售话术红线）

✔ 可说："文件指纹 SHA-256 真实计算、篡改 1 字节即被发现、凭证可打印可扫码核验。"
