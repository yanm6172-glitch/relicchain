# 08 上海落地与融资作战计划（v1.0）

> 基于团队现状定制：上海 · 与建为历保合作过博物馆扫描（手中有文物照片）· 团队全能 · 有比赛经历、无投资人接触。

## 1. 底牌盘点

| 资产 | 价值 | 风险 / 待办 |
| --- | --- | --- |
| 建为历保合作经历 + 碧水寺摩崖造像扫描照片 | 国保单位项目、真实数据、行业关系 | 数据版权几乎肯定归采购方（绵阳市博物馆）或按合同归建为——**商用前必须书面确认** |
| 上海 | 博物馆密度高（备案博物馆 160 余家，2024 年接待观众超 4000 万人次）、文创产业与政策强 | 竞争也激烈，要选对切入点 |
| 团队"都会" | 执行快、人力成本低 | 投资人要的是"分工与负责人"，尤其销售负责人 |
| 比赛经历 | 背书雏形 | 继续打，同一个故事一以贯之 |

## 2. 最大杠杆：建为历保（先打这张牌）

**它是什么**：上海建为历保科技股份有限公司——从事建筑文化遗产利用性策划、设计、施工及文化遗产物联网监测管理的高新技术企业，正冲刺国内文化遗产保护"第一股"。**它上市需要"数字化 + 区块链"板块的故事，你们恰好是它缺的那块拼图**——你们的议价空间比想象中大。

**三种合作姿势（按难度递进）**：

| 姿势 | 内容 | 你们的收益 |
| --- | --- | --- |
| A. 分包 / 渠道 | 它接的馆，你们做扫描后数据处理、存证、验证页 | 项目现金 + 渠道背书 |
| B. 联合产品 | 用手里的扫描照片做"文物数字资产存证演示"，双品牌 | 演示物料 + 信用背书 |
| C. 伙伴 → 标的 | 它上市后需要战投/并购标的，你们是熟悉且便宜的 | 长期退出路径 |

**本周动作**：联系当年的对接人，三选一目标——
1. 拿到这批照片的**商用/演示书面授权**；
2. 转介 **1 家博物馆客户**；
3. 签一份**合作备忘录**。

**红线**：扫描照片版权大概率归博物馆或按合同归建为。未授权商用 = 侵权 + 馆方信任破产，学生团队赔不起，也别拿照片直接做产品。

## 3. 上海客户地图（先易后难）

- **策略**：不先攻上海博物馆（体量大、决策慢）。先攻：**行业馆、民营馆、区级馆、校史馆、非遗中心**。
- **候选**：纺织博物馆、航海博物馆、中医药博物馆、世博会博物馆、龙美术馆、观复博物馆（上海馆）、各区博物馆；学校校史馆、文博/考古系老师的人脉。
- **最热线索**：绵阳市博物馆（碧水寺摩崖造像数字化保护项目的采购方）与碧水寺寺方——你们参与过该项目、认识项目相关人，是第一客户候选；同类扩展：摩崖造像/石窟寺数字化（川渝石窟带是蓝海）。
- **打法**："免费小样换意向函"——挑 1 件文物免费做全套（采集优化 → 存证 → 验证页 → 溯源页），交付时签意向或收费合同。

## 4. 上海政策与资金清单（写 BP 前以官方最新为准）

| 渠道 | 内容 | 适合阶段 |
| --- | --- | --- |
| 上海市大学生科技创业基金会"天使基金" | 雏鹰计划（债权资助，最高 50 万，还款后可转股权）；股权资助最高 80 万（2026 年进校园宣讲口径） | 现在就可申请 |
| 上海市创业担保贷款 | 个人/组织创业担保贷款 + 贴息 | 注册公司后 |
| 上海市文创资金 | 促进文化创意产业发展财政扶持资金、各区文创园区入驻补贴 | 有项目后 |
| 大赛 | 互联网+、挑战杯、"汇创青春"上海大学生文创作品展、大学生创新创业训练计划 | 学期内 |

**打法**：天使基金是申请制、看团队与项目——用**比赛奖项 + 博物馆意向函**去申请，命中率高。

## 5. 60 天作战表

| 周 | 动作 | 产出 |
| --- | --- | --- |
| 1–2 | 联系建为（授权/转介/备忘三选一）；盘点碧水寺摩崖造像照片资产（数量/质量/元数据） | 授权书或备忘 |
| 3–4 | 挑 10 件文物做存证 demo（开放联盟链：蚂蚁链/至信链），验证页 + 溯源页 | 可演示产品 |
| 5–6 | 拜访 3–5 家馆，免费小样换意向函 | 意向函 ×1+ |

**60 天 KPI：1 封授权/意向函 + 10 件存证 demo + 1 份 BP + 1 个大赛报名。**
