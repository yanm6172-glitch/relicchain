# 23 操作演示视频脚本（手机竖屏版 · 1 分钟）

> 用途：发给馆方/投资人的"产品操作"短视频。竖屏 9:16，录屏手机操作即可。

## 一、分镜（6 镜头）

| # | 时长 | 画面 | 配音 |
| --- | --- | --- | --- |
| 1 | 0:00–0:08 | 手机桌面 → 打开"文博链"图标（PWA 安装后） | "文博链，装在手机里的文物数字档案。" |
| 2 | 0:08–0:22 | 登录 museum → 登记页 → 填表 → 📸 拍照取证 → 点"登记并上链" → 挖矿动画 → 4/4 确认 | "登记一件文物：填信息、拍一张取证照，照片指纹随登记写入链上。" |

| 5 | 0:50–1:00 | 切管理员 → 审计日志滚动 → 存证凭证打印 | "机构治理与审计全程留痕，凭证即开即打。" |

## 二、拍摄要点

1. 用 PWA 形态拍（启动APP.bat + 手机添加主屏幕），更有"APP 感"；
2. 提前备好：一张打印的凭证二维码（真码）、一件待登记文物的照片；
3. 挖矿动画是全片记忆点，给 2 秒特写；
4. 结尾加字幕：文博链 RelicChain · 让每件文物可信、可查、可传承。

## 三、与 3 分钟版的关系

- 3 分钟版（路演视频脚本.md）：讲原理与商业，面向评委/投资人；
- 1 分钟版（本文档）：讲操作与效果，面向馆方/合作方/朋友圈传播；
- 顺序建议：先发 1 分钟版预热，见面时播 3 分钟版，现场用真机演示平台。
