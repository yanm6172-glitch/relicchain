# 11 数字化采集与建模服务设计（当前主打方向）

> 承接 docs/10 的方向 A。一句话：卖的不是软件，是"高精度、可交付、合规的文物数字化成果"。

## 1. 定位与差异化

- **定位**：面向文博单位的一站式数字化采集与建模服务商；
- **垂直切口**：摩崖造像/石窟寺 + 可移动文物（碧水寺实战经验背书）；
- **差异化（对大公司）**：小团队 → 响应快、报价灵活、贴身服务；懂文保（文物等级、操作禁忌、元数据规范）；
- **与 SaaS 方向衔接**：每次交付自带"数字档案包"（元数据 + 文件指纹清单），为方向 B 埋种子。

## 3. 一物四层（复用 L0–L3 分级，核心定价武器）

| 级别 | 精度 | 用途 | 交付格式 | 定价档 |
| --- | --- | --- | --- | --- |
| L0 档案级 | ≤0.05mm | 修复与研究 | 原始点云 + 高模 | 最高 |
| L1 研究级 | ≤0.2mm | 研究/出版 | 高模 + 纹理 | 中高 |
| L2 展示级 | 轻量化 | 线上展示 | GLB / web3D | 中 |
| L3 传播级 | 动图/短视频 | 社交传播 | 二维码 / 小程序 | 低 |

**核心卖点：一次采集、四次交付——一次成本、四层收入。**

## 4. 工艺流程（10 步）

1. 踏勘与需求确认（材质反光/透明、尺寸、光照、现场禁忌）
2. 采集方案设计与设备标定
3. 现场采集（点云 + 纹理）
4. 数据预处理（配准、去噪、抽稀）
5. 网格重建与逆向建模
6. 纹理映射与精修
7. 质检（精度、完整性）
8. 元数据与建档（对齐普查规范）
9. 分级输出转换
10. 交付与验收（按验收清单）

## 5. 工艺难点与对策

| 难点 | 对策 |
| --- | --- |
| 反光金属/玉器 | 喷粉或交叉偏振采集 |
| 透明玻璃 | 表面涂层，或 CT 方案（外包） |
| 大型摩崖 | 无人机摄影测量 + 地面激光融合 |
| 丝织品/纸质文物 | 非接触、低照度、防损流程 |
| 暗光环境 | 补光方案 + 色卡校色 |
| 高精度要求 | 标定板 + 基准点 + 结果抽检 |

## 6. 设备与技术栈

| 环节 | 选型 | 说明 |
| --- | --- | --- |
| 手持采集 | EinScan Pro HD / Artec Eva 档（8–15 万） | 初期租借，回款后购入 |
| 桌面采集 | 转台 + 结构光 | 小型器物高性价比 |
| 摄影测量 | 微单 + Metashape / RealityCapture | 摩崖/大场景主力 |
| 大场景 | 无人机 + 地面激光（租赁） | 按项目租 |
| 后处理 | Blender / ZBrush / CloudCompare / MeshLab | 开源为主 |
| 展示 | three.js / model-viewer / 小程序 GLB | 团队现成能力 |
| 建档 | 元数据模板（后续升级为 SaaS） | 方向 B 的种子 |

**设备策略**：初期用学校实验室 + 建为设备（租借），首批回款后买一台中端手持——现金流永远先于资产。

## 7. 质量与交付标准

- 精度按 L0–L3 分级执行（见第 3 节）；
- 格式：原始点云 PLY / OBJ / FBX / GLB / 档案 PDF（含元数据 + 指纹清单）；
- 命名规范：馆藏编号_级别_版本_日期；
- 验收：精度抽检、模型完整性、纹理色差、元数据齐全（清单见 docs/12）。
