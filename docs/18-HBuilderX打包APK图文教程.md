# 18 HBuilderX 打包 APK 图文教程（10 分钟出包）

> 目标：把 区块链平台.html 打包成可安装的安卓 APP（带图标、全屏、摄像头权限）。

## 第 1 步 · 下载安装 HBuilderX

- 官网 dcloud.io 下载 **HBuilderX（App 开发版）**，解压即用，免费；
- 首次运行需要登录（免费注册 DCloud 账号）。

## 第 2 步 · 新建 5+App 项目

```
文件 → 新建 → 项目 → 5+App → 新建 Wap2App 项目
├── 项目名称：文博链
├── 模板：空白模板
└── 创建
```
- 打开项目根目录的 `manifest.json`。

## 第 3 步 · manifest.json 配置（关键）

| 页签 | 配置项 | 填什么 |
| --- | --- | --- |
| 基础配置 | 应用名称 | 文博链 |
| 基础配置 | AppID | 点击"云端获取"（自动分配，免费） |
| 基础配置 | 版本号 | 1.4.0 |
| 图标配置 | 图标 | 上传 `icon-192.png`（本包已提供） |
| 模块权限 | 摄像头 | ✅ 勾选（扫一扫必需） |
| 模块权限 | 存储 | ✅ 勾选（下载凭证文件用） |
| 页面入口 | 首页地址 | `http://服务器地址/区块链平台.html` 或本地 `file://` 路径 |

## 第 4 步 · 云打包生成 APK

```
发行 → 原生App-云打包
├── Android
├── 使用公共测试证书（个人演示用，免费）
├── 包名：com.relicchain.app
└── 打包
```
- 约 3–5 分钟出包，控制台给出下载链接 → 下载 APK → 传到手机安装。

## 第 5 步 · 正式交付（替换测试证书）

- 正式交付馆方需**自有安卓证书**（manifest.json 里可生成 keystore，注意备份）；
- 生成证书 → 云打包选"使用自有证书" → 以后每次更新用同一证书，才能覆盖安装。

## 常见报错速查

| 报错 | 解决 |
| --- | --- |
| 打包失败：证书错误 | 重新生成证书，或改用公共测试证书 |
| 安装提示"来源未知" | 手机设置允许安装未知来源应用 |
| 扫一扫黑屏 | 手机设置里给 APP 开摄像头权限 |
| 页面打不开 | 首页地址须是 http:// 或 https://，不能是电脑本地路径（手机访问不到） |
| 想离线不联网用 | 把整个文件夹拷进 APP 资源目录（HBuilderX 本地工程），首页地址填相对路径 |

## 分发三选一

1. **直接分发**：APK 发微信/网盘，对方直接安装（演示期首选）；
2. **应用商店**：需软著 + 企业主体 + 隐私政策（长期目标）；
3. **小程序**：微信小程序路径见 docs/17 第 6 节（摄像头 API 更稳）。
