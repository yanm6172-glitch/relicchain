# 22 交付与验收标准（商品交付规范）

## 1. 交付流程

```
签订意向/合同(30% 定金)
→ 需求确认(馆方提供文物清单与现有数据)
→ 实施(采集/建档/部署/培训)
→ 交付(50% 款)
→ 验收(按本清单, 20% 尾款 7 日内)
```

## 2. 交付物清单（勾选）

- [ ] 平台部署可用（本地服务或 PWA，账号可登录）
- [ ] 约定的 N 件文物完成登记（含元数据 + 指纹 + 链上区块可查）
- [ ] 拍照取证照片指纹与链上记录一致（抽查 ≥ 20%）
- [ ] 存证凭证打印/下载正常（抽 1 件演示）
- [ ] 扫码核验闭环演示通过（真码或手动编号）
- [ ] 账号与权限按角色正确隔离
- [ ] 培训完成（馆方人员可独立操作）
- [ ] 文档交付：使用说明 + 平台使用手册 + 本验收清单

## 3. 验收标准（可测）

| 场景 | 标准 |
| --- | --- |
| 登记 | 提交后 10 秒内区块可查，4/4 节点确认 |
| 验证 | 篡改 1 字节必判"被篡改"（3 次抽查全过） |
| 溯源 | 任意事件 5 秒内链上核验 |
| 容错 | 刷新/重启后数据仍在（同机） |
| 安全 | 未授权角色无法写入（公众身份验证） |

## 4. 售后

- 免费：30 天远程支持（微信/邮件）；
- 付费：全年支持、上门服务、新功能定制（按人天 800–1500 元）。
