# 12 报价与交付模板

> 配套 docs/11。所有数字为经验假设，第一单后必须用真实成本校正。

## 1. 成本结构（单件可移动文物，中等复杂度）

| 科目 | 金额 | 说明 |
| --- | --- | --- |
| 人力（现场 1–2 人天 + 后处理 2–5 人天） | 3000–8000 元 | 学生人力成本按市场价 6 折计价即可 |
| 设备折旧/租赁 | 500–1500 元 | 租借为主 |
| 软件授权摊销 | 200–500 元 | 开源为主则更低 |
| 差旅 | 上海本地忽略；外地另计 | 报价单单列 |

**毛利目标：40%+。报价起点 = 成本 ÷ (1 − 0.4)。**

## 2. 报价模型

| 方式 | 区间 | 说明 |
| --- | --- | --- |
| 按件（小型） | 2000–6000 元 | 玉器、铜镜、小造像 |
| 按件（中型） | 6000–15000 元 | 陶瓷器、佛像、俑 |
| 按件（大型/复杂） | 15000–50000 元 | 大件器、龛窟 |
| 按天（现场机组） | 5000–10000 元/天 | 2 人 + 设备 |
| 项目打包 | 10–30 万 | 批量采集 + 建档 + 展示页 |

**分级系数**：L1 为基准；L0 档案级 ×1.5–2；L2/L3 打包加 30–50%。
**示例**：碧水寺式摩崖造像 1 龛 ≈ 2–5 万（含 L0–L2）。

## 4. 付款节奏（保护现金流）

- **30% 定金**（进场前）→ **50% 交付时**（文件交付）→ **20% 验收后 7 日内**；
- 小单（<5000 元）：全款预付；
- 学生团队对外姿态：这是行业惯例，不是我们苛刻。

## 5. 合同要点

1. 成果版权归委托方；**我方保留署名权与案例展示权（必须书面约定）**——这是作品集的法律基础；
2. 交付标准以附件《验收清单》为准；
3. 委托方负责文物出库、场地与安全配合；
4. 保密条款（文物数据敏感）；
5. 免费修改次数限制（建议 2 次，超出按天计费）。

## 6. 验收清单（勾选式）

- [ ] 格式齐全：点云 / 模型 / 纹理 / 建档 PDF
- [ ] 精度抽检达标（与实测标注比对）
- [ ] 模型无破洞、翻面、重面
- [ ] 纹理色差在容差内
- [ ] 命名规范：馆藏编号_级别_版本_日期
- [ ] 档案 PDF 含文件指纹清单（SHA-256）

## 7. 数字档案包（给方向 B 埋种子）

每次交付附带：元数据表 + 每个文件 SHA-256 指纹清单 + 采集参数记录。

**话术**："您的数字资产自带指纹——以后任何人拿着您的模型，都能验证是不是原版。"（哈希校验不需要区块链，这是 SaaS 的钩子。）

## 8. 毛利测算示例

| 情形 | 报价 | 成本 | 毛利 |

| 单件 L1+L2 | 8000 元 | 4500 元 | 44% |
| 摩崖 1 龛 L0–L2 | 30000 元 | 16000 元 | 47% |
| 批量项目（20 件） | 120000 元 | 70000 元 | 42% |

**保本点：每月 1.5 单中型，或 3 单小型。**
