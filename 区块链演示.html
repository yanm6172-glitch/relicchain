① 看看一条链长什么样

下面三个区块已经连成一条链。每个区块都记着前一个区块的哈希——像锁链一样一环扣一环。

找规律：区块 #2 的「前块哈希」= 区块 #1 的「本块哈希」。这就是"链"。

② 添加一笔登记（体验挖矿）

登记一件文物。注意看：新块不是随便加的——计算机要不停尝试 nonce（随机数），直到算出的哈希以 N 个 0 开头。这叫工作量证明（挖矿）。

③ 试着篡改数据

现在当一回"坏人"：把区块 #2 里的登记内容偷偷改掉。看整条链会变成什么样。

④ 验证整条链

任何人（比如公众）都可以把每个区块重新算一遍，检查两件事：① 哈希是不是真的以 N 个 0 开头；② 「前块哈希」是否对得上。

⑤ 为什么修不回去？

坏人不死心：把篡改过的区块重新挖矿，让它自己的哈希"合法"。试试会发生什么。

🎉 你已看懂区块链的核心：哈希链接 + 工作量证明 = 不可篡改。真实世界里还有 4–7 个机构节点各存一份，多数不同意就永远改不成。
